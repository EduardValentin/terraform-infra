# Phase 0 Prerequisites

This is the current prerequisite baseline for the infrastructure that is live today.

## Required now

### Tailscale

- Tailnet exists and is healthy.
- MagicDNS is enabled.
- Host tags, CI tags, and tag owners match the policy generated by `infra/envs/controlplane/main.tf`.
- The current Tailscale tag defaults and override knobs live in `infra/envs/controlplane/variables.tf`.
- One OAuth client exists for CI automation with `Auth Keys: Write` and the CI tags allowed by the Terraform policy.
- Reusable pre-auth keys exist for long-lived host bootstrap and recovery only; their target tags come from the control-plane bootstrap variables.
- Tailscale SSH is enabled for admin identities according to `tailscale_ssh_destinations`.
- Public SSH stays closed on PROD.

### GitHub

- Repositories exist:
  - `EduardValentin/course-platform`
  - `EduardValentin/terraform-infra`
- GitHub environments exist where required by `infra/envs/controlplane/variables.tf`.
- Required repository secrets and variables are configured as described in `docs/GITHUB_SECRETS_MATRIX.md`.
- Repository variables include stable node hostnames for CI SSH target resolution as consumed by the runtime secret and app deploy workflows.

### Runtime secret management

- Local `age` keypair is generated for SOPS.
- `.sops.yaml` contains the correct age public key.
- The runtime secret workflow has the SOPS age private key secret it consumes.

### Terraform backend

- OPS VM is running and reachable over Tailscale.
- OPS bootstrap has MinIO backend enabled.
- `terraform-infra` repository secrets are set for every secret referenced by `.github/workflows/terraform-plan.yml` and `.github/workflows/terraform-apply.yml`.

## Optional later

### Public DNS automation

Cloudflare is supported by the repository but is not required for the current TEST and OPS setup.

Only add Cloudflare prerequisites when public DNS will actually be managed from Terraform:

- Create or choose the public zone.
- Create a token with:
  - `Zone:DNS:Edit`
  - `Zone:Zone:Read`
- Add the token and zone id to the relevant Terraform variable payloads.

## Done criteria

- Tailscale ACL policy applies cleanly and tags are assignable.
- GitHub repositories have the required secrets and variables.
- Runtime secret encryption and decryption work end to end.
- Terraform plan can initialize against the OPS-hosted backend.
- Cloudflare prerequisites are only required when public DNS automation is activated.
